# 0070. ビルドした画面に、同梱したものの表示を 1 つのファイルで残す

- 状態: 採用
- 日付: 2026-10-03

## 背景

`make build` が作る `web/dist` は、`bin/etoki` と一緒に配られる（ADR 0032）。
**その中に、同梱したもののライセンスの表示が 1 つも残っていなかった**（#215）。

- **束ねた依存のコメントが落ちる。** Vite 8（rolldown）は縮小するときに
  `comments.legal` を既定で `false` にする。React や Excalidraw が持っている
  `@license` のコメントも成果物には残らない。
- **フォントは束ねていない。** キャンバスの手書きフォントは
  `@excalidraw/excalidraw` の `dist/prod/fonts` を丸ごと写している
  （`vite.config.ts` の `excalidrawFontAssets`）。パッケージにライセンスの
  ファイルが無く、どこにも表示が無い。
- **ソースに写したものも同じ。** #214 で Tabler Icons（MIT）の線画を
  `web/src/board/menuIcons.tsx` に写した。コメントに `@license` を付けても
  成果物からは消える。

## 決定

**`web/dist/third-party-notices.txt` に、3 つの口から集めたものを 1 つにまとめて
書く。** 組み立ては `web/build/thirdPartyNotices.ts` の Vite プラグイン。

| 口                 | 集め方                                                                     |
| ------------------ | -------------------------------------------------------------------------- |
| 束ねた依存         | Vite の `build.license`。本文の無いパッケージは `packageNotices.ts` で補う |
| フォント           | `fontNotices.ts` に家族ごとの著作権とライセンスを手で持つ                  |
| ソースに写したもの | 束ねたモジュールの先頭の `/*!` か `@license` のコメントを拾う              |

### 表示が欠けたらビルドを止める

**欠けても画面のどこにも出ず、気づく機会が無い。** 次のどれでもビルドが落ちる。

- 配っているフォントの家族と `fontNotices.ts` が食い違う（Excalidraw を上げて
  家族が入れ替わった）
- 束ねたパッケージに本文が無く、`packageNotices.ts` にも無い。補いのライセンスが
  パッケージの `license` と食い違う。どのパッケージにも使われない補いがある
- ソースの先頭のコメントに著作権の表示があるのに、`/*!` も `@license` も無い

### 写したものの一覧を別に持たない

**表示は写したファイルの先頭に置けば、それだけで載る。** 一覧を別に持つと、
写した人が書き忘れる場所が 1 つ増える。印を付け忘れた形（説明と表示を 1 つの
コメントにまとめる）は上の 3 つ目で止まる。

### 書き出す先はドットで始めない

Vite の既定は `.vite/license.md`。etoki 自身の配信（`http.Dir`）はドットで
始まる場所も配るが、`web/dist` を別の配信元に載せると届かないことがある。
`.txt` にしたのは、Markdown の Content-Type が配信元によって決まらず、ブラウザが
その場で開かないことがあるため。**画面からのリンクは置いていない。** 表示の
要件は成果物に含めることで、画面で見せる場所はまだ決めていない。

### ライセンスの本文は推測で書かない

`web/build/licenses/` の本文は SPDX の license-list-data から写した。フォントの
著作権の行は、配っているファイルの name テーブルと、配布元のライセンスの
ファイルの両方から写した。2 つが違うものは両方を載せている。

**Liberation Sans だけは OFL ではない。** Excalidraw が同梱しているのは 1.05 で、
Liberation Fonts が OFL-1.1 に移った 2.00 より前の版。1.x は GPLv2 に
フォントの例外を付けたもので、Red Hat の使用許諾（1.07.4 の `License.txt`）と
GPLv2 の本文を両方載せている。

## 帰結

- Excalidraw や依存を上げた PR は、表示の更新が要るとビルドで落ちる。
  Dependabot の PR も同じ。落ちたら、メッセージが指すファイルを直す。
- 写したものの表示は、説明のコメントと分けて置く必要がある（#214 の形は
  そのままでは止まる）。

## 採らなかった案

- **`build.rolldownOptions.output.comments.legal: true` でコメントを残す。**
  依存ごとにコメントを持っているかどうかがまちまちで、持っていないパッケージの
  表示は残らない。束ねたチャンクのあちこちに散るので、何が入っているかも読み
  にくい。フォントもこの経路には乗らない。
- **Vite が書く Markdown の後ろに書き足す。** 本文の無いパッケージを補えず、
  補わずに通すと MIT の著作権表示が欠けたまま残る。`build.license` には
  `.json` を書かせ、読んでから 1 つのファイルに組み直す。
- **`bin/etoki` に焼いた Go の依存の表示も同じ PR で扱う。** 配る先が画面ではなく
  バイナリで、置き場所から決め直すことになる。別に扱う。
