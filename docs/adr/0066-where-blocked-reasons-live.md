# 0066. 押せない理由はボタンの隣に置き、待たされる操作だけ外に残す

- 状態: 採用
- 日付: 2026-09-29

## 背景

etoki は押せない理由を `title` に隠さず、本文として出して `aria-describedby` で
ボタンと結んでいる（ADR 0039、`.claude/rules/async-ui.md`）。`title` を禁じたのは、
ホバーでしか読めず、`disabled` なボタンにはフォーカスも当たらないので、キーボード
と読み上げの利用者に理由が届かないためだった。

ADR 0065 で、たまに押す操作が `MainMenu` の中に入る。**しまうと、理由も一緒に
隠れる。** 閉じているあいだ読めないという点で、`title` を禁じたときの問題が別の
形で戻ってくる。

「しまうのをやめる」と、ヘッダーに 12 個並んでいた状態に戻るだけなので（ADR 0064）、
**しまう／しまわないの線をどこに引くかを決める必要がある。**

## 決定

**線は理由の種類ではなく、「誰が、いま何を見ているか」で引く。**

### 理由はボタンの隣に置く

押せない理由は、そのボタンの隣に本文で出す。**ボタンがメニューの中にあれば、
理由もメニューの中に出す。** メニューは開けばフォーカスが入るので、キーボードと
読み上げには届く。`title` のように「読めないのに説明が付いているように見える」
状態にはならない。

形はヘッダーにあったころと変えない。権限や設定で押せない操作はボタンごと出さずに
理由の文を出し（ADR 0030 / 0017）、一時的に押せない操作は押せないボタンと理由を
`aria-describedby` で結ぶ。

### 外に残すのは、待たされている本人が見ている操作だけ

**保存と「GitHub に作成する」は外に置いたままにする。** 保存は右上、作成は注釈
の詳細の下端の帯（ADR 0065、#201）。

この 2 つは相互に排他していて（`.claude/rules/async-ui.md`）、片方を押した人は
もう片方の前で待たされる。「作成が終わるまで保存できません」は、**いままさに
反応を待っている人に向けた文**なので、その人が見ている場所で読めなければ意味が
無い。メニューを開かせて読ませては届かない。

### それ以外は、一時的な理由があってもしまってよい

取り込み・作成先の変更・削除などは、保存中や作成中に押せなくなることがあっても
メニューに入れてよい。**押そうとした人はメニューを開くので、項目の隣で理由が
読める。** 待っている人が見ている場所ではないので、外に出しておく理由が無い。

## 帰結

- **`blockingReasons` は変えない。** あれは下書きだけを見て「作るものが揃って
  いるか」に答える純関数で、進行中かどうかを知らない（`web/CLAUDE.md`）。一時的
  な理由はこれまでどおり UI の側で持つ。この ADR は置き場所の話で、判定の持ち方
  の話ではない。
- **`web/e2e/a11y.spec.ts` に、メニューを開いた状態を足す。** 「開かないと DOM に出ない
  領域は、開いた状態を 1 つずつ足す」（`web/CLAUDE.md`）に 1 つ増える。足さないと、
  しまった先の理由が消えても検査は緑のまま通る。
- **「出さない」を確かめる spec は、メニューを開いてから見る。** 閉じたメニューの
  中身は DOM に無いので、閉じたまま `toHaveCount(0)` を見ると、出していても通る。
- 理由の要素の `id` を注釈ごとに分ける約束はそのまま。メニューに 1 つしか出さない
  理由だけが固定の `id` でよい。

## 採らなかった案

- **一時的な理由を持つ操作はしまわない。** この ADR の最初の版はこう決めていた。
  実装してみると、取り込みも作成先の変更も保存中や作成中に止まるので外に残る
  ことになり、ADR 0064 が解こうとした並びが戻る。しかも外に出しておく理由だった
  「待っている人に向けた文」は、この 2 つには当たらない（待たされているのは保存か
  作成のほう）。**理由の種類で線を引くと、守りたかった人とは別の人のために外に
  置くことになる。**
- **全部しまう。** 保存と作成の前で待っている人が、理由を読むためにメニューを
  開くことになる。
- **全部外に出す。** ADR 0064 が解こうとした 12 個並びに戻る。
- **しまったボタンが押せないときだけ、メニューの外（`≡` の隣）に理由を出す。**
  何の理由なのかが、開いていない相手には分からない。理由だけが宙に浮く。
