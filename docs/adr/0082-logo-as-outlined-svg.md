# 0082: ロゴは字を輪郭にした SVG で持ち、色は絵の側に固定する

ステータス: 採用

## 文脈

etoki にはロゴが無く、どの画面も名前を文字の「etoki」だけで出していた。MCP の
同意の画面だけが仮のロゴ（#185）で、ブラウザのタブにはファビコンが無かった
（#245）。

意匠は、大きな筆が墨で「絵解き」を書き上げた絵（若葉色の地に墨）に決まった。
字は毛筆の書体（Yuji Boku、SIL Open Font License 1.1）で書いてある。etoki は
外の配信元から書体を取らない（#114）。

## 決定

### 字は書体の輪郭にして、図形として置く

Yuji Boku の字形の輪郭をパスにして SVG に置き、**書体のファイルは配らない。**

- 使うのは 3 字だけで、そのために数 MB の書体を配る理由が無い。
- `<text>` のまま置くと、見る人の手元の書体で描かれる。`<img>` の中の SVG は
  ページの書体を読まない。
- **`third-party-notices.txt`（ADR 0070）には載せない。** あの表示は同梱した
  もの（束ねた依存・配っている書体・ソースに写したコード）のためのもので、
  ロゴは書体で書いた絵であって書体そのものではない。OFL も書体で作った絵に
  表示を求めていない（OFL FAQ 1.1.2）。出どころは各 SVG の先頭のコメントに
  残す。

### 大きさごとに絵を分け、3 つの SVG を正本にする

叩き台（#245）は「SVG 1 つを正本にし、画面に置くものとファビコンをそこから
作る」だった。**これは採らない。** 筆と 3 字の絵は 32px では潰れ、払いと荒れは
16px では黒い染みになる。

| ファイル       | 置く場所                 | 中身                                      |
| -------------- | ------------------------ | ----------------------------------------- |
| `logo.svg`     | ログインの画面           | 筆と「絵解き」の全体                      |
| `logoMark.svg` | 一覧の上の帯・同意の画面 | 角丸の地に「絵」の一字と払い（32px 前後） |
| `favicon.svg`  | ブラウザのタブ           | 角丸の地に「絵」の一字だけ（16px）        |

1 つの SVG から切り出す形（`<view>` やフラグメント）も採らない。構図が
違うので、切り出す範囲が無い。

### 色は絵の側に固定し、`tokens.css` から引かない

**`web/CLAUDE.md` の配色の約束（規則に色を直書きしない）の例外にする。**
あの約束は、ダークで変数を差し替えたときに直書きの箇所だけ明るく残るのを
防ぐためのもの。ロゴは地ごと色を持つ絵で、**ライトでもダークでも同じに
見せたい。** 若葉色の地はダークの面でも沈まない（#245 の「ダークでも
沈ませない」はこれで満たす）。

- `<img>` の SVG はページの CSS 変数を読めない。ファビコンはページの外で
  描かれるので、どう置いても読めない。
- インラインの SVG（React のコンポーネント）にすれば帯と同意の画面だけは引ける
  が、ファビコンだけが別の色の決め方になる。同じ絵が 2 つの決め方を持つ。

### `<img>` で置き、絵は読み上げから外す

- 名前は文字の「etoki」が持つ（`alt=""`）。見出しの名前は変わらない。
- SVG をページに展開しないので、フィルタや `clipPath` の id がページの中で
  衝突しない。React に書き写せば、正本が SVG と写しの 2 つになる。

### ファビコンは SVG だけを置く

- **PNG は置かない。** 焼く道具をビルドに足すことになり、正本が 2 つになる。
  SVG のファビコンを描けないブラウザでは、タブが既定の絵に戻るだけで、使え
  なくなるものは無い。
- **`index.html` から `web/src/app/favicon.svg` を指し、Vite に名前を付けて
  配らせる。** `web/public/` に固定の名前で置くと、ロゴを直した日もブラウザが
  古いファビコンを持ち続ける。etoki の配信がキャッシュさせないのは
  `index.html` だけで（`internal/httpapi/webui.go`）、名前にハッシュが入る資産は
  変えた日に別の名前になる。

## 採らなかった案

- **書体を配り、`<text>` で書く。** 上の「字は書体の輪郭にして」。
- **1 つの SVG を縮めて全部に使う。** 上の「大きさごとに絵を分け」。
- **色を変数から引く。** 上の「色は絵の側に固定し」。
- **PNG のファビコンも置く。** 上の「ファビコンは SVG だけ」。

## 結果

- 絵を直すときは案から書き出し直す。**字を `<text>` のまま持ち込むと
  `web/src/app/logo.test.ts` が落ちる。** 外を指す参照も同じ。
- 3 つの SVG は「絵」の字形をそれぞれに持つ。直すなら 3 つとも直す。
- 描けていることは `web/e2e/logo.spec.ts` が 3 つの画面とファビコンで見る。
  SVG が XML として壊れても `<img>` は空の箱になるだけで、名前は文字が
  持っているので、ほかの検査は落ちない。
