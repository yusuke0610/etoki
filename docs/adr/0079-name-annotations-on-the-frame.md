# 0079: 囲みの名前は絵解きの面で付け、frame の name にそのまま書く

ステータス: 採用

## 文脈

名前の無い囲みは、一覧で「絵1」「絵2」と補った見出しで出る（ADR 0078）。
この番号は一覧の中の位置で、キャンバスのラベル（名前が無ければ Excalidraw が
`Frame` と描く）とは一致しない（ADR 0022）。どの囲みかは、カードを押して
キャンバスを寄せるまで分からない。

名前を付ける手段は Excalidraw のフレームのラベルをダブルクリックすることだけで、
etoki の画面からは気づけなかった。囲みの名前は解釈の入力でもあるので、絵解く
直前に整えたいのに、その場（絵解きの面）では触れなかった。

## 決定

### 名前は絵解きの面で付ける

名前の欄を、絵解きの面の粒度と種別の隣に置く。名前も解釈の入力なので、「絵解く」
を押す直前に整えられる場所に置く。読むだけのロールでは変えられない。

### 書く先は frame の `name` そのもの

- **キャンバスのラベルにも同じ名前が出る。** 一覧とキャンバスの名前が揃い、
  どの囲みかが番号ではなく名前で分かる。
- **名前を変えると `content_hash` が変わる。** frame の `name` は解釈の入力の
  テキストとして足される（`internal/domain/scene.go` の `AnnotationTexts`）ので、
  ハッシュにも LLM への入力にも入る（ADR 0036）。作成済みの囲みの名前を変えると
  「変更あり」になる。**これは受け入れる。** 名前は人が読む見出しであると同時に
  解釈の材料で、変えたものを「変わっていない」と扱う理由が無い。
- 驚かせないよう、**作成済みの囲みでは、名前の欄に「変えると『変更あり』に
  なります」と添える。** 未作成なら影響が無いので言わない。

### 確定したときだけ書く

- 確定は Enter か、欄を離れたとき。1 文字ごとに書くと、打つたびに未保存になり、
  「元に戻す」に 1 文字ずつ積まれる。
- **変換中の Enter では書かない。** 日本語の変換を確定する Enter で書くと、変換の
  途中の名前がキャンバスに載る。
- **Escape は書きかけを捨てるだけにする。** 書きかけが無いときだけ面を閉じる。
  書きかけを捨てたつもりで面ごと閉じると、何を捨てたのかが見えなくなる。
- **「絵解く」は押しても焦点を奪わない。** 欄を離れた瞬間に未保存になると、
  本文に保存の案内（ADR 0077）が出て帯が下へずれ、押し始めたボタンが指の下から
  逃げる。書きかけは、押した処理の中で確定してから読む。

## 採らなかった案

- **表示用の名前を `customData.etoki` に別に持ち、`content_hash` から外す。**
  名前を変えても状態は変わらないが、注釈のメタデータの形は Go と TypeScript の
  2 箇所に同じものがあり（ルートの `CLAUDE.md`）、共有のテストデータ、契約、
  ハッシュの仕様まで動く。導入した時点で、既存の囲みが一斉に「変更あり」に
  見えないかも確かめ直すことになる（ADR 0047 で一度起きた）。キャンバスの
  ラベルには出ないので、一覧との食い違いも残る。
- **入力するたびに書く。** 上の理由で、未保存と「元に戻す」が 1 文字ずつ動く。

## 結果

- 名前を付けた囲みは、一覧・絵解きの面・キャンバスで同じ名前になる。
- 作成済みの囲みは、名前を変えると「変更あり」になり、更新の候補になる。
- パネルの中の「注釈」という語（「注釈 3 件」など）は、この作業でも変えていない。
  画面の名前を「絵解いた」「絵N」にした（ADR 0078）あとで、その語で使う人が
  迷うかを画面で確かめてから決める。
