# 0095. 線を揺らさず、書体を Excalifont から外す

- 状態: 採用
- 日付: 2026-10-31

## 背景

Excalidraw の既定は手書き風で、線を揺らし（roughness 1）、書体は Excalifont。
etoki のボードでは「ラフすぎて読みにくい」と感じる場面が多かった。

特に効いていたのが日本語。Excalidraw は Excalifont に無い CJK の字を、手書き風の
中国語書体（Xiaolai）で描く。**この置き換えは Excalifont のときだけ起きる。**
付箋の言葉はほぼ日本語なので、線より先に字が崩れて見えていた。

キャンバスを自前で作り直す案も出たが、見た目のためだけに frame の帰属判定まで
自分で持つことになる（ADR 0036 / 0047）ので採らない。見た目は Excalidraw の
設定で変えられる。

## 決定

**線は揺らさず（roughness 0）、書体は Nunito にする。** 人が描くものにも、
etoki が置くもの（ひな形・表・図のドラフトと mermaid の貼り付け）にも当てる。
片方だけにすると、どれが etoki の置いたものかが見た目で分かれてしまう。置いた
ものを手で描いたものと区別しないのは ADR 0063 / 0069 と同じ理由。

書体を Nunito にしたのは、Excalidraw の書体の選択肢に並ぶ手書き風でない書体
だから。Excalifont 以外なら日本語は手書き風に置き換わらない（0.18.1 時点）。

### 既存のボードは書き換えない

保存済みの要素は、揺れる線と Excalifont のまま残る。開いたときに etoki が
書き換えると、人が描いたものを etoki が勝手に変えることになる（中核思想 3）。
しかも開いただけで未保存になる。直したければ、全選択して線と書体を選び直す。

### 人が選び直すのは止めない

既定を変えるだけで、Excalidraw の線と書体の選択はそのまま残す。手書き風で
描きたい人は選べる。選び直した値は、ボードを開いているあいだだけ効く。

## 結果

- 見た目は作成済みかどうかの判定に使っていないので、変えても作成済みの
  draft issue の状態は動かない。
- 新しく描いたものと既存のものが、同じボードの中で見た目が違うことがある。
