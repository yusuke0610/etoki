# 0083: 設定の案内に載せる環境変数の名前は、配線だけが持つ

ステータス: 採用

## 文脈

「設定されていない」ときの案内に、環境変数の名前が 3 層に分かれて書かれていた
（#273 の DRY 違反の調査、#280）。

- 画面の文言（`web/src/api/errorMessage.ts`）: 「`ETOKI_LLM_API_KEY` を設定して
  ください」
- サーバーの本文（`internal/httpapi` の `*NotConfigured` と Origin の拒否）:
  「set ETOKI_LLM_API_KEY or ETOKI_LLM_BASE_URL」
- 名前の定義と、何で有効になるかの判定（`cmd/etoki` とアダプタの `ConfigFromEnv`）

**すでに食い違っていた。** LLM が使えるかは `BaseURL` か `APIKey` のどちらかで
決まり、サーバーはそう案内しているのに、画面は API キーだけを言っていた。
名前を変えた日には、存在しない名前を案内し続ける。

もう 1 つ、**名前を出すこと自体が誤りになる構成がある。** `etoki.New` に自前の
`LLMClient` を渡す外部リポジトリ（ADR 0001 / 0008）は環境変数を読まない。
それでも `ETOKI_LLM_*` を設定せよと案内していた。

## 決定

**環境変数の名前を知っているのは配線（`cmd/etoki`）だけにする。**

- `etoki.Options.SetupHints` に、機能ごとの案内文（何を設定すればよいか）を
  渡す口を足す。`cmd/etoki` が、アダプタの公開定数から組み立てて渡す。
  - **`internal/httpapi` はアダプタを import しない。** 依存の方向
    （ハンドラ → ユースケース → port）に反する。案内文は値として受け取る。
- サーバーは案内文を `error` 本文に載せる（「llm is not configured: <案内>」）。
  **渡されていなければ載せない。** 外部実装を差し込む構成では、存在しない
  `ETOKI_*` を案内しない。cross-site の拒否（ADR 0013）と、認証なしで公開した
  ときの起動時の警告も同じ口から引く。
- 案内は**機能ごと**に持つ（LLM / GitHub / 認証 / 許すオリジン）。共有と MCP の
  接続は認証を設定すれば開くので、認証の案内を使う。**`*_not_configured` の
  code ごとには持たない。** 同じ設定で開くものを別々に渡すと、片方だけ古くなる。
- **画面の文言（`ERROR_MESSAGES`）から名前を消す。** 何が足りないか（LLM /
  GitHub / ログイン）と、起動する側で設定するものだということまでを言う。
  **「API キーかエンドポイントか」のような、どれがあれば使えるかも言わない。**
  それも配線が決めることで、写すと今回の食い違いと同じ形でずれる。名前は
  サーバーの本文として「詳細」に出る（ADR 0034 の畳み方のまま）。

## 採らなかった案

- **名前を今の置き場所に残し、食い違いだけを直す。** 変更は小さいが、名前の
  二重定義が残り、外部実装を差し込む構成でも `ETOKI_*` を案内し続ける。
- **どこにも出さず README に任せる。** いちばん単純だが、手元で使う人が
  何を設定すればよいかを画面から辿れなくなる。
- **`capabilities` の応答に案内文を載せ、押す前にも名前を出す。** 契約を
  広げる変更になる。押した後の「詳細」で名前は読めるので、今回は入れない。

## 結果

- **押す前の案内（ADR 0030、`capabilities` から引く文言）には名前が出なく
  なる。** 「LLM が未設定」までは押す前に読め、何という変数かは押した後の
  「詳細」か README で読む。押す前と押した後で文言が同じ、という ADR 0030 の
  約束はそのまま（どちらも `ERROR_MESSAGES` から引く）。
- ADR 0034 が `*_not_configured` を畳まない理由として挙げた名前
  （`ETOKI_LLM_API_KEY` など）は例示で、画面に名前を出せという決定ではない。
  畳まない判断はそのまま残る（設定するものが違う）。
- 名前を変えるときに直すのは、アダプタの定数と `cmd/etoki`（usage と README の
  照合は `readme_test.go`）だけになる。
