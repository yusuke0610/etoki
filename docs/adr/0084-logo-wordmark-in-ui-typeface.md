# 0084: ロゴは UI の書体で書いた名前の文字にし、字の色はテーマから引く

ステータス: 採用

ADR 0082 を置き換える。

## 文脈

ADR 0082 で入れたロゴは、大きな筆が墨で「絵解き」を書き上げた絵だった。
若葉色の地ごと色を持つ絵なので、`<img>` で置き、色を SVG の中に固定していた。

意匠を変えた（#245）。筆と毛筆の字をやめ、**名前の英字「etoki」そのものを
ロゴにする。** i の点だけを少し傾けた緑の四角（付箋）にする。ホワイトボードに
貼った付箋から始まる道具であることを、その 1 点で言う。

今度のロゴは地を持たない文字なので、ライトの字の色のままではダークの地に
沈む。etoki のテーマは OS の設定に従うだけでなく、利用者が手で切り替えられる
（`web/src/app/theme.ts`）。

## 決定

### 字は UI の書体（Assistant Bold）で書き、輪郭にして持つ

- **UI と同じ書体にする。** ロゴは一覧の上の帯で、ボタンやメニューの英数字と
  並ぶ。別の書体だと、そこだけ字形が浮く。
- **書体のまま書かず、輪郭（パス）にする。** i の点を付箋に差し替えるので、
  付箋の位置が字形の寸法に結びつく。書体で書くと、読み込みを待つあいだや
  手元の書体に替わったときに付箋だけが字から外れる。
- **部品の字形は `third-party-notices.txt`（ADR 0070）に載せる。** 字形の
  輪郭をソースに写しているので、ソースに写した第三者のものとして扱う。
  ADR 0082 は載せなかったが、あれは SVG のファイルで、束ねたモジュールでは
  なかった。
- **ファビコンの SVG は、出どころを先頭のコメントに残すだけにする。** 束ねる
  モジュールではないので、ビルドは表示を拾わない。書体そのものの表示は、画面の
  書体として配っているぶんで、すでに載っている（`web/build/fontNotices.ts`）。

### ページに置くロゴは React の部品（インラインの SVG）にする

**ADR 0082 の「`<img>` で置く」を改める。** 字の色をテーマに従わせるには、
ページの側の色を読める必要がある。

- 字は置いた場所の文字色（`currentColor`）で描く。テーマを切り替えれば字も
  切り替わる。
- 付箋は変数（`--brand-note`）から引く。**ダークでも同じ色にする。** 字では
  なく印の一部で、テーマで色を変えると別の印に見える。
- 名前は SVG の `aria-label` が持つ。ロゴが名前の文字そのものなので、飾りとして
  読み上げから外し、隣に文字を並べる形（ADR 0082）はもう取らない。見出しの名前は
  「etoki」のまま変わらない。

ADR 0082 が `<img>` を選んだ理由のうち、「フィルタや `clipPath` の id がページの
中で衝突しない」は、今度の絵が id を持たないので当たらない。「正本が SVG と
React の写しの 2 つになる」は、部品そのものを正本にして SVG のファイルを
置かないことで避ける。

### ファビコンだけは SVG のファイルで、色を固定する

ファビコンはページの外で描かれ、テーマも変数も読めない。付箋の緑の角丸に
黒の e を置き、色は SVG の中に固定する。緑は `--brand-note` と同じ値を写して
持つ。**写しなので、ずれたら単体テストで落とす。**

- **`index.html` から `web/src/app/favicon.svg` を指し、Vite に名前を付けて
  配らせる。** `web/public/` に固定の名前で置くと、ファビコンを直した日も
  ブラウザが古いものを持ち続ける。etoki の配信がキャッシュさせないのは
  `index.html` だけで（`internal/httpapi/webui.go`）、名前にハッシュが入る資産は
  変えた日に別の名前になる。
- **PNG は置かない。** 焼く道具をビルドに足すことになり、正本が 2 つになる。
  SVG のファビコンを描けないブラウザでは、タブが既定の絵に戻るだけ。

## 採らなかった案

- **`<img>` のまま、ライト用とダーク用の 2 枚を置く。** テーマの切り替えに
  合わせて差し替える仕組みが CSS の側に要り、同じ字形を 2 枚が持つ。
- **SVG の中で `prefers-color-scheme` を見る。** `<img>` の SVG が見るのは OS の
  設定で、etoki で手で切り替えたテーマは届かない。
- **SVG のファイルを文字列で読み込み、ページに展開する。** 部品に書けば済む
  ものに、HTML を差し込む口を作ることになる。
- **ロゴを置かず、帯の見出しを書体のまま書く。** 付箋の点が書けない。

## 結果

- ロゴの正本は `web/src/app/Wordmark.tsx`（ページ）と `web/src/app/favicon.svg`
  （タブ）の 2 つ。e の字形は両方が持つので、字を直すなら両方直す。
- 名前は `aria-label` が持つので、字が描けなくても、ダークの地に沈んでも、
  画面の名前と読み上げは変わらない。字がテーマの色で描けているかは、描いた
  色を見ないと分からない。
