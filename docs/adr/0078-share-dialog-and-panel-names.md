# 0078: メンバーは右のパネルから外して「共有」のダイアログで開き、パネルの名前を使う人の言葉に寄せる

ステータス: 採用

## 文脈

右のパネルには「注釈」「図のドラフト」「メンバー」の 3 つのタブが並んでいた
（ADR 0065）。3 つを 1 か所に集めたのは、開く場所がばらばらで開くたびに
キャンバスの形が変わっていたのを直すためだった。

並べてみると、3 つは答えている問いが違った。

- 「注釈」と「図のドラフト」は、**ボードの中身に対する作業**。囲んだものを
  絵解きし、ブレストに図を足す。描きながら何度も開く。
- 「メンバー」は、**ボードそのものの管理**。誰と共有するかを決め、たまに開く。

名前も使う人の言葉になっていなかった。「注釈」は etoki の内部の名前で、
使う人がしているのは「frame で囲む → 絵解く」である。「図のドラフト」は何を
するタブかが伝わらない。名前の無い囲みに補う見出し（「注釈 1」）も、同じ
内部の名前を画面に出していた。

## 決定

### メンバーはメニューの「共有…」からダイアログで開く

- **右のパネルから外す。** パネルにはボードの中身に対する作業だけを並べる。
- **キャンバスのメニューに「共有…」を置き、ブラウザの `<dialog>` をモーダルで
  開く。** メニューはたまに押す操作の置き場所（ADR 0065）で、共有はそこに当たる。
  モーダルのダイアログはキャンバスの形を変えないので、ADR 0065 が解いた
  「開くたびにキャンバスの形が変わる」には戻らない。
- **誰にでも出す。** 一覧は読むだけの人にも見え、招待と解除はダイアログの中で
  オーナーにだけ出る（ADR 0017）。共有が組み立てられていない構成でも口は消さず、
  開いた先で理由を出す（ADR 0030）。
- **閉じたら中身は外し、開くたびに一覧を引き直す。** パネルのタブは書きかけを
  残すために描いたまま隠したが、共有は手早く済ませる操作で、招待の書きかけが
  閉じると消えても打ち直せば足りる。開いているあいだだけ引くので、押したとき
  だけ引く約束も保てる。
- 閉じたら、焦点をメニューの口へ戻す。開いた項目はメニューごと消えているので、
  戻さないと焦点が body に落ちる。

### 名前は画面の文言だけ変える

| いま                         | 変更後      |
| ---------------------------- | ----------- |
| 「注釈」のタブ               | 絵解いた    |
| 「図のドラフト」のタブ       | etoki AI    |
| 名前の無い囲みの見出し       | 絵1、絵2    |
| キャンバスに重ねる枠のバッジ | 絵、絵 epic |

- **コード・契約・ADR の用語（`annotation`、`diagramDraft`）は変えない。** 画面の
  名前は使う人に向けたもので、今後も変わりうる。そのたびに型や API の名前まで
  追随させると、契約と生成物が動き、変更の範囲が画面の外へ広がる。
- **パネルの中の文言（「注釈 3 件」「注釈にする」など）は今回は据え置く。** 中身の
  言葉を揃えるかは、囲みに名前を付ける作業（#249）と合わせて決める。
- **名前の無い囲みの見出しは表示だけで補う。** frame の `name` には書かない。
  `name` は `content_hash` の入力なので、書くと見出しを補っただけで状態が
  「変更あり」に落ちる（ADR 0036）。
- **重ねる枠のバッジには番号を付けない。** 一覧の番号は一覧の中の位置で、
  キャンバスの並びとは一致しない（ADR 0022）。番号を付けると、同じ番号が違う
  囲みを指して見えうる。

## 採らなかった案

- **メンバーを右のパネルに残す。** 開く場所は 1 つのままだが、ボードの中身に
  対する作業と、ボードの管理が同じ並びに見える。タブが 1 つ減れば、畳んだ帯も
  短くなる。
- **共有を別の画面にする。** 入力は少なく、URL を持つ画面を増やすほどではない
  （新しいボードのダイアログと同じ理由、#200）。画面を移るとキャンバスが外れ、
  未保存の確認（ADR 0021）を通すことになる。
- **共有をモードレスのダイアログにする**（注釈の詳細と同じ形）。開いている
  あいだにキャンバスや詳細を触れると、招待の途中で別の操作が割り込む。
  共有はその場で済ませる操作なので、外を触れなくしたほうが状態が単純になる。

## 結果

- 右のパネルのタブは 2 つになる。畳んだ帯にも 2 つだけが並ぶ。
- ADR 0065 の「注釈 / 図のドラフト / メンバーを etoki の右パネルに置く」のうち、
  メンバーの行はこの ADR で置き換わる。
- 共有のダイアログを開いているあいだは、キャンバスもパネルも触れない。
