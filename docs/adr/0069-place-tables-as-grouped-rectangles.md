# 0069. 表は空の矩形を group にして置き、行と列としては読ませない

- 状態: 採用
- 日付: 2026-09-30

## 背景

issue #67 の残りは「表をすぐ置けるようにする」。付箋は ADR 0063 で Excalidraw の
矩形ツールに任せると決めたが、表は違う。`@excalidraw/excalidraw` 0.18.1 には
表のツールも表の要素も無く、表計算の貼り付けもグラフになる。**矩形を並べて
自作するしかない。**

付箋は 1 枚描けば足りるが、表は行 × 列の枚数が要る。複製で並べる手数が
付箋より大きいので、ボタンで置く価値が残る。

## 決定

**キャンバスのメニューの「表」で、3 列 × 3 行の空の矩形を見えている範囲の中央に
置く。** 置いた表は選んだ状態にする。

- **矩形 9 枚を Excalidraw の group にまとめる。** ドラッグで 1 つの表として
  動かせ、解除すれば個別のセルに戻る。**frame は作らない。** frame を自前で
  生成しない線（ADR 0036 / 0047）は、境界にまたがる要素の帰属判定を etoki が
  持たないための線で、group は所属を要素自身が持つだけなので触れない。
- **大きさは固定。ダイアログを挟まない。** 描いている最中の連続的な操作なので、
  手数の少なさが値打ち（#52 のひな形・#58 の AI 生成との違い）。足りなければ
  複製やセルの追加で広げる。
- **全セル同じ大きさ・白地。見出し行を区別しない。** 1 行目に色を付けると、
  etoki が「1 行目は見出し」と決めたことになる（中核思想 2）。塗り分けは
  人が行う。
- **中身は空。** 仮の文字を置くと、消し忘れが `content_hash` と解釈の入力に
  並ぶ。
- **`customData` を付けない。** 手で描いた矩形と区別しない（ADR 0063 の付箋と
  同じ）。区別すると、その印から意味を読むコードを書きたくなる。
- **「元に戻す」1 回で表ぜんぶが消える。** `updateElements` を通すので、
  #144 の方針のとおり 1 手で積まれる。

## 採らなかった案

- **行数・列数を入力させる（ダイアログ／ポップオーバー）。** 1 手で置けるという
  前提が崩れる。
- **線で罫線を引く。** セルに文字を入れるには別の text が要り、文字がセルに
  属する `containerId` の仕組みを使えない。
- **group にしない。** 動かすたびに範囲選択が要る。group は要素側が持つ
  だけの情報で、etoki の側に判定を増やさない。

## 結果

- **置いた表は etoki のどの機能ともつながらない。** 解釈にも `content_hash` にも、
  手で描いた矩形と同じ形で入る。表を行と列として読ませる実装を書かないこと。
  読ませたいものは、既存のとおり並び順と画像に任せる（ADR 0018）。
- 表の見た目や大きさを変えたくなったら、ボタンを直す前に Excalidraw の
  操作で足りないかを確かめる（ADR 0063）。
