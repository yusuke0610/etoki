# 0037: 作成先の表示名は固定後も取り直せる（固定するのは作成先そのもの）

ステータス: 採用

## 文脈

`project_number` / `project_title` / `project_url` は作成先を選んだ時点の
スナップショットで、判定には使わない（ADR 0019 / 0025）。**古くなったら選び直しで
直す**、と決めてあった。

ところが `BoardService.SetTarget` は固定済みなら値を見ずに `ErrTargetLocked` を
返す。同じ `projectId` を送り直しても弾かれる。つまり **draft issue を 1 件でも
作ったボードでは、選び直しができない = 表示名を直す手段が無い。** GitHub 側で
Project を改名すると、そのボードのサイドバーは古い名前を出し続ける。

一覧はリポジトリと Project でまとめて見せる（ADR 0019）ので、古い名前のままだと
木のグルーピングが実態とずれる。そして「自動で GitHub に取りにいって書き戻さない」
と決めてある以上、手で直す口が塞がっているのは仕様の隙間になる。

ADR 0014 が固定する理由は「作成先が変わると `sync_runs` が指す item を見失う」
こと。**表示名の更新はこの理由に当たらない。**

## 決定

- **固定するのは作成先そのもの（owner / name / projectId）だけにする。** 表示用の
  3 つは固定の対象ではない。`SetTarget` の固定判定はこれまでどおり動かさない。
- **表示用のスナップショットだけを更新する経路を別に持つ。**
  `PUT /api/boards/{id}/target/display` と
  `BoardService.RefreshTargetDisplay`、`port.BoardRepository.UpdateTargetDisplay`。
  **`SetTarget` の判定を緩めない。** 緩めると「変更できた」と「たまたま同じ
  だった」を呼び出し側が区別できなくなる（`SetTarget` がもともと同値の送り直しを
  弾いていた理由）。
- **リクエストは `projectId` を伴い、保存済みのものと違えば 409（`target_mismatch`）。**
  この口から作成先は動かせない、を構造で示す。`ErrTargetLocked` に相乗りさせない
  のは、直し方が違うため。固定は解けないが、食い違いは画面を開き直せば解ける。
- **権限は owner のみ。** 作成先の変更と揃える（ADR 0017）。
- **etoki から自動で取りにいかない。** 画面に「作成先の名前を取り直す」を出し、
  押されたときだけ GitHub を引く（中核思想 3）。開いただけで更新すると、ボードを
  開くたびに GitHub を叩くうえ、変わったことに気づく機会が消える。
- **判定材料は増やさない。** `BoardTarget.Selected` は 3 つしか見ない。

## 結果

- 固定済みのボードでも表示名を直せる。作成先そのものは固定されたままなので、
  `sync_runs` が指す先を見失う道は塞がっている。
- 表示用の 3 つを書ける経路が 2 つになった（`UpdateTarget` と
  `UpdateTargetDisplay`）。**作成先の 3 列を書けるのは前者だけ。** ここが崩れると
  固定が意味を失う。
- 更新は `updated_at` を進める。ボードの行が変わった以上、版は進める（ADR 0020）。
  画面は応答のボードで手元を差し替える。

## 採らなかった案

- **`SetTarget` の固定判定を「作成先の 3 つが変わる場合だけ」に絞る。** 1 つの口が
  「作成先の変更」と「表示名の更新」を兼ねることになり、409 が返ったときに
  どちらを断られたのかが呼び出し側から読めない。
- **固定済みでも選び直し画面を開かせる。** 名前を直すためだけにリポジトリと
  Project を選び直させることになる。選び直しは「作成先を変える」操作なので、
  変えられない状態で開かせるのは状態の見せ方として嘘になる。
- **ボードを開いたときに GitHub から取り直す。** 自動で判断せず状態を見せて
  選ばせる（中核思想 3）に反する。ボードを開くたびに GitHub を叩くことにもなる。
- **逆方向同期の一部として取り込む。** GitHub → ボードの同期はスコープ外。
  これは 1 つの Project の表示名だけを、押されたときに取り直す操作にとどめる。
