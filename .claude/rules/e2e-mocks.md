# 偽物の厳密さ

CodeRabbit のレビューで繰り返し出た落とし穴。緩い偽物は「偽物だけが
古い契約のまま緑になる」を招く（ADR 0012）。生成型・ルート述語・境界の
例外は `web/CLAUDE.md` にあり、ここには書かない。

**下の 2 節は E2E のモック（`web/e2e/`）の話。** Go で書いた偽の上流
（`internal/fakeupstream/`）は最後の節にある。

## ルートの縛り方

- **ルートは HTTP メソッドを検査する。** 契約のメソッド以外は
  `route.fallback()` でキャッチオールに落とす。クライアントがメソッドを
  間違えても E2E が緑のままになるため。target / members / auth に入れて
  interpret だけ抜けていた、という形で漏れやすい（#29 / #26 / #28 / #25）。
- **パスはアンカー付きの述語で完全一致させる。** `endsWith` の末尾一致は
  間違ったパスでも成功応答を返す（#21）。
- **モックの判定はサーバーと同じ契約にする。** 必須フィールドの欠落は
  409 ではなく 400、というように、サーバーが返す区別をモックでも守る。
  モックだけが緩いと、フロントの送り忘れを競合テストが隠す（#69）。
- **省略された任意フィールドは、作成側と同じ既定値に落とす。** スプレッド
  で前の値を残すと、省略したのに古い値が生きているボードが返る（#75）。
- **書き込みで置き換えた値からサーバーが導出するフィールドも、同じ応答で
  更新する。** シーンを置き換えて `sceneOverLimit` を残すと、開き直しても
  実 API と違う状態が返る。導出元だけを差し替えるスプレッドで漏れる（#131）。
- **壊した応答も、入れ物の形だけは契約に合わせる。** 壊すのは中身の要素で
  あって応答そのものの形ではない。トップレベルが配列からオブジェクトに
  変わったのに `[null]` を返し続けると、**画面が中身に触る前に形で落ちる**
  ので、確かめたかった描画の失敗とは別の経路を見ることになる。壊す口を
  複数の契約で共有しているなら、本文は呼び出し側から渡す（#123）。

## リクエストの検証

- **記録した本文を読む前に、応答後にしか出ない表示を待つ。** `click()` は
  応答を待たずに返るので、待たずに `mock.createRequests` を読むと空配列を
  見て通りうる。待ち方は expect.poll ではなく、そのファイルが既に使って
  いる表示待ち（`.waitFor()` など）に揃える（#74）。
- **画面の遷移だけでなく、期待するリクエストが飛んだことも断言する。**
  同じ表示を別の実装で作っても通るため。`page.waitForRequest` で
  メソッドとパスを縛る（#26）。

## 手元の通し確認に使う偽の上流（`internal/fakeupstream`）

E2E モックと同じ理屈が、Go で書いた偽の GitHub / LLM にも効く（ADR 0050）。
違うのは、こちらは**本物のアダプタが相手**なので、緩さが「通しだけが緑」を
作るところ。

- **偽物を本物より甘くしない。** 同じ識別子を運ぶ操作は、**全部で同じ判定を
  する**。`projectId` を作成では見てフィールド一覧では見ない、のように片方
  だけ甘いと、向き先を取り違えたアダプタにも一覧が返り、フィールドの更新も
  成功扱いになる（#138）。
- **偽物がプロンプトの文言を読むなら、走査するのは自分が組み立てた側だけ。**
  利用者は付箋に何でも書けるので、**マーカーと同じ文字列はどれも本文側に
  現れうる**（粒度の「issue 相当」、前回一覧の見出し、`- p9 (issue) …` の行）。
  全文を走査すると、付箋 1 枚で粒度の判断が変わったり、存在しない ref を
  返したりして、本物の検査に弾かれ**通しが理由の見えない失敗になる**。
  絞るのは 1 つのマーカーではなく全部（#138、2 周かかった）。
- **読んだ文言はテストで固定する。** 偽物がプロンプトを読む以上、文言を変えた
  側は気づけない。本物のメッセージを組み立てて偽物に食わせる契約テスト
  （`internal/usecase/fakeupstream_contract_test.go`）を同時に足す。

## やらないこと

- **`ApiMock` のプロパティに代入するリテラルへ `Reply<T>` を重ねない。**
  プロパティ型が生成型なので、代入の時点で検査済み。明示しても検査は
  増えない（#81 で撤回済み）。
- **`breakList` 系の壊れた本文を型に通さない。** 壊れていること自体が
  テストの入力。キャストで形だけ通すと意図が隠れる（#85 で確定、
  `web/CLAUDE.md` の例外）。
