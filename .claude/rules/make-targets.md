# Makefile の recipe

Makefile のターゲットで実際に踏んだ穴。`##` の説明と `CLAUDE.md` のコマンド
説明のずれは `docs-consistency.md` が見ているので、ここでは recipe の中身だけを
扱う。

## 上書きできる変数

- **上書きを前提にした変数（`?=` で置くもの、`make X=…` で渡すもの）は、
  読む recipe すべてで `"$(X)"` と引用してシェルに渡す。** 1 箇所だけ直すと、
  同じ変数を読む別のターゲットに同じ指摘が来る（#157）。

## 利用者のデータに触るターゲット

- **SQLite のファイル（`-wal` / `-shm` を含む）を消す・置き換えるターゲットは、
  etoki が動いたまま呼ばれる前提で組む。** WAL の接続は消えたファイルを掴んだ
  まま読み書きし、その書き込みは閉じた時点で消える。例は `reset-db`（#157）。
